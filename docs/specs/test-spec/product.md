# 製品背景 (product.md) — ToDo サンプル

## 概要
このドキュメントは、ToDo サンプル機能に関する製品的な背景と目的を簡潔に示します。

## 課題
- ユーザーが日々のタスクを簡単に記録・管理できるシンプルなインターフェースが必要。

## ゴール
- 最低限の CRUD 機能を提供し、学習やプロトタイピングに使える状態にする。

## スコープ
- フロントエンドは想定内で API に対して CRUD を行う設計。
- 認証は今回のスコープ外（必要なら別タスクで追加する）。

## KPI（学習向け）
- 基本機能の実装完了までの時間
- テスト網羅率（簡易）
